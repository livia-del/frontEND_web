# 資管系學會系統 — 純前端版

直接用瀏覽器開啟 `index.html` 即可。無須 XAMPP、PHP 或 MySQL。

功能：會員新增/修改/刪除、搜尋、CSV 批次匯入與匯出、最新消息 CRUD、活動建立與報名、名單 CSV 匯出、會員角色管理。

資料保存在瀏覽器 localStorage；換瀏覽器或清除網站資料會遺失。帳號切換只是示範，**沒有真正登入與安全權限**，請勿儲存真實個資。

匯入 CSV 範例見 `members_example.csv`，欄位需為 `student_id,name,email,class_name`。準備包含上述欄位的 UTF-8 CSV，管理者可在會員管理點選「批次匯入」。也支援中文欄名：學號、姓名、Email、系級。匯入前會檢查必填欄位與 Email 格式；重複學號略過，新會員預設為啟用的一般會員，完成後顯示新增及略過筆數。

設計：無左側導覽列；上方四個資料夾標籤；霧白與深海軍藍配色。
